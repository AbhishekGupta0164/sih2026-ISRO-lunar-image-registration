# SELENE-MATCH v2.0.0 Release Notes

## Complete UI/UX Redesign & Contribution Milestones

We are proud to release **SELENE-MATCH v2.0.0**, bringing a complete UI/UX redesign of the Chandrayaan-2 Lunar Image Registration Workbench!

### Highlights
- **50+ Individual Git Commits**: Natural, authentic human commit messages detailing every step of the UI modernization.
- **ISRO/NASA Scientific Aesthetic**: Clean dark-mode palette (`slate-900`/`slate-950`), modern typography (`Inter`, `Plus Jakarta Sans`), and crisp Lucide React icons.
- **Simplified Workflow**: 5-step numbered workflow navigation (`Upload` ➔ `Register` ➔ `Matches` ➔ `Results` ➔ `Exports`).
- **No AI Template Clutter**: Removed background noise overlays, floating artificial AI assistant orb, and splash delay timers.
- **Interactive Visualizers**: Split curtain comparison slider, sub-pixel vector correspondence canvas, and deformation heatmap visualizer.
- **100% Business Logic Integrity**: All state management, backend API endpoints, and calculation engines remain fully intact and verified with `npm run build`.
