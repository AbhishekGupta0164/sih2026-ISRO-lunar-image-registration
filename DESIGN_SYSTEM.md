# SELENE-MATCH Design System

## Typography
- **Primary Body**: Inter (`font-sans`)
- **Headers & Display**: Plus Jakarta Sans (`font-display`)
- **Monospace / Telemetry**: JetBrains Mono (`font-mono`)

## Color Palette (Dark Mode First)
- **Background Base**: `#0a0d14` / `slate-950`
- **Surface Elevation**: `#0f1420` / `slate-900/60`
- **Borders & Dividers**: `slate-800` (`rgba(255, 255, 255, 0.08)`)
- **Primary Accent**: Sky Blue (`#38bdf8` / `text-sky-400`)
- **Success / Inliers**: Emerald (`#10b981` / `text-emerald-400`)
- **Warning / Outliers**: Amber (`#f59e0b` / `text-amber-400`)

## Component Tokens
- **Cards**: `p-6 rounded-2xl border border-slate-800 bg-slate-900/60 backdrop-blur-md`
- **Primary Buttons**: `px-4 py-2.5 rounded-lg text-xs font-semibold bg-sky-500 hover:bg-sky-400 text-white shadow-md shadow-sky-500/20`
- **Ghost Buttons**: `px-4 py-2.5 rounded-lg text-xs font-semibold bg-slate-900 border border-slate-800 text-slate-400 hover:border-slate-700`
- **Badges**: `text-xs font-mono px-2.5 py-1 rounded border`
